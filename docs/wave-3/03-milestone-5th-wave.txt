Make reputation cost something, and extend the loop beyond HTTP APIs.

1. Staking-weighted attestations with slashing. A score counts payments: every point is backed by a real transaction, so it is expensive to forge — but unstaked, so a seller risks nothing by serving badly. Done when attestors stake OG behind an attestation, a challenge can be raised on-chain, and a successful one slashes the stake, with scores recomputed stake-weighted.

2. Agent-to-agent payment. The same 402 loop prices anything metered per call, including 0G inference and storage. Done when a registered service is itself an agent selling compute, and one agent pays another through PaymentRouter with no human key at either end.

Order matters: the rail must be general and budget-safe before it is worth staking on. Slashing without on-chain budgets lets a buyer overspend into a dispute it cannot afford.
